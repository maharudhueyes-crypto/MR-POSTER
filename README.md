# Deploy (easy way)
1. Ellaa files-ayum GitHub repo-la upload pannu (.env podaadhe).
2. Render.com -> New -> Blueprint -> repo select. render.yaml thaan disk + settings ellam set pannum (Starter plan, always-on).
3. Env values fill pannu: BASE_URL (Render URL), RZP_KEY, RZP_SECRET, RZP_PLAN_ID, WEBHOOK_SECRET.
4. Razorpay: Rs.759 monthly plan + webhook https://URL/api/webhook (events: subscription.activated/charged/cancelled/halted/completed).
5. Meta: Page ID, Instagram ID, long-lived Page token -> app form-la paste -> "Post now".
Check: https://URL/health -> "ok".
Note: poster text English-ku set. Tamil text venumna server-la Tamil font (Noto Sans Tamil .ttf) add pannanum.
